# IPTV for ALL

تطبيق مجاني لمشاهدة القنوات المجانية المفتوحة.

## التحميل
من صفحة [آخر إصدار](../../releases/latest):
- **Windows:** `IPTVforALL-…-Setup.exe`
- **Android TV / تلفزيون:** `IPTVforALL-…-armeabi-v7a.apk` (يشتغل على أغلب التلفزيونات)
- **أجهزة Android حديثة:** `IPTVforALL-…-arm64-v8a.apk`

بعد التثبيت، التطبيق يحدّث نفسه من "تحديث التطبيق".
